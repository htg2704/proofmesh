ProofMesh is a shared evidence rail for media claims. Its web workspace and X extension are the first clients of a common API. It separates image identity from the exact caption and publication context: related media never inherits another claim's verdict. Gemini on Vertex AI researches claims, assesses fetched source quotations and critiques conclusions; Cloud Vision supplies matching-page leads. Cloud Run, Firestore and Cloud Tasks preserve investigations and reuse. Visitors get limited browser workspaces automatically; third parties can use scoped, revocable REST keys or run their own deployment. Twelve prespecified development cases produced 11 expected outcomes; all twelve exact repeats made zero model calls. This small set is not representative accuracy, and provider capacity failures remain documented. Missing evidence stays unresolved; no universal AI-origin detector is claimed. SDK/MCP and platform integrations are future options.
