ProofMesh is a shared evidence rail for media claims. The web workspace and X extension are its first clients. It separates image identity from the exact caption and publication context: a related image never inherits another claim's verdict. Gemini on Vertex AI researches the claim, assesses fetched source passages and critiques its conclusion. Conclusive findings require exact source quotations. Cloud Vision supplies image-matching leads; Firestore persists reports and jobs, Cloud Tasks delivers work, and Cloud Run hosts the portal. A separate reviewer workspace protects team reports. Twelve prespecified development cases produced 11 expected outcomes; all twelve exact repeats made zero model calls. This small set is not representative accuracy, and provider capacity failures remain documented. Missing evidence stays unresolved; no universal AI-origin detector is claimed. The public demo includes synthetic and recorded live examples. New reviewer checks use a private access link and bounded allowance.
