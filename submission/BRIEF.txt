ProofMesh adds reusable, source-linked context to media claims in X feeds. It keeps image identity separate from the exact caption: a related image never inherits another claim's verdict. Gemini on Vertex AI researches claims with Google Search, assesses fetched source passages and critiques its conclusions. Cloud Vision supplies image-matching leads. Cloud Firestore, the Firebase document database, persists investigations, jobs and transactional limits; Cloud Run hosts the portal/API, Cloud Tasks delivers durable work, and private Cloud Storage holds temporary images. Secret Manager protects credentials. Four selected exact repeats made zero additional model calls. Missing evidence stays unresolved; no universal AI-origin detector is claimed. The public prototype includes synthetic and recorded live examples; arbitrary new live checks require the team token. See the public repository for measured evaluation and limitations.
