ONE RAIL, MANY APPLICATIONS

Evidence that can travel with the claim.

ProofMesh keeps investigations behind a common API, so each app can retrieve the same evidence with its context and limits intact. This web workspace and the X extension are the first clients.

Future integrations could bring the rail into social platforms, Android or Gemini experiences, and AI agents through an MCP adapter. These integrations are proposals; no platform partnership or MCP server is included in this build.
