Use the REST API from your own application. No SDK or MCP server is required.

A private workspace for each key

The public examples are deliberately shared. Your new reports and related-image results are isolated from other clients. Each key permits bounded requests and investigations. Shared spending and provider-capacity limits also apply.

Just testing in the browser? Open the app. It handles access automatically; no code is needed.

The server stores a hash. Keys expire after 30 days and the owner can revoke them. Never commit this file or put keys in URLs.

Three operations

Look up evidence: POST /api/v1/matches
Investigate: POST /api/v1/jobs, then GET /api/v1/jobs/{id}
Retrieve: GET /api/v1/investigations/{id}

Send your key in the Authorization: Bearer header. A 429 response includes Retry-After. Reusing fresh evidence does not consume an investigation admission, but still counts as an API request. A 503 can indicate the shared trial spending guard; team rate exemptions do not bypass that guard.
